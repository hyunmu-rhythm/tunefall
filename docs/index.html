TUNEFALL

좋아하는 곡을 넣으면 채보가 만들어지는 4키 리듬게임

곡 링크를 붙여넣으면 박자와 악기를 분석해서 EASY, NORMAL, HARD 세 가지 채보를 자동으로 만들어 줘요. 같은 곡은 언제나 같은 채보가 나와서 기록 경쟁도 할 수 있어요.

최신 버전을 확인하는 중이에요
Windows 10, 11 (64비트) 전용 무료 게임

D F J K 를 눌러 직접 쳐 보세요

이런 게임이에요

DJMAX처럼 위에서 떨어지는 노트를 판정선에 맞춰 치는 키보드 리듬게임이에요.

  • 곡 링크로 채보 자동 생성

    곡을 악기별로 나눠 분석한 뒤, 곡의 빠르기와 밀도에 맞춰 1~30 난이도의 채보를 만들어요.

  • 손맛 나는 판정

    Perfect, Great, Good, Miss 판정과 FAST / LATE 표시, 키를 누를 때 켜지는 키빔과 판정 이펙트가 있어요.

  • 내 환경에 맞추는 싱크

    비프음에 맞춰 떨어지는 노트로 소리 지연과 판정선 위치를 직접 맞출 수 있어요.

  • 만든 곡은 친구와 공유

    채보가 만들어진 곡을 zip 파일로 내보내서 친구에게 보낼 수 있어요. 기록은 빼고 보내져요.

시작하기

설치부터 첫 플레이까지 순서대로 따라 하면 돼요.

  1. 설치하기

    내려받은 TUNEFALL_Setup.exe를 실행하세요. 관리자 권한 없이 설치되고, 바탕화면에 바로가기가 생겨요.

  2. 싱크 맞추기

    설정에서 싱크 조절 화면을 열고, 비프음에 맞춰 Space를 눌러 보세요. 자동 적용을 누르면 내 PC에 맞는 값이 저장돼요.

  3. 곡 추가하기

    곡 선택 화면에서 곡 링크를 붙여넣고 ADD를 누르세요. 곡 길이에 따라 몇 분 정도 걸리고, 인터넷 연결이 필요해요.

  4. 플레이하기

    D F J K로 노트를 치고, ESC로 일시정지해요. 게임 중에 Z C로 노트 속도를 바꾸고 X로 기본 속도로 돌아가요. 키는 설정에서 바꿀 수 있어요.

패치 노트

업데이트가 나오면 게임을 켤 때 알려 줘요. 추가한 곡과 기록은 업데이트해도 그대로 남아요.

자주 묻는 질문

여기서 해결되지 않으면 Discord에 남겨 주세요.

설치할 때 “Windows의 PC 보호” 창이 떠요

개인이 만든 게임이라 아직 디지털 서명이 없어서 나오는 안내예요. 창에서 추가 정보를 누른 뒤 실행을 누르면 설치할 수 있어요.

“애플리케이션 제어 정책에서 이 파일을 차단했습니다”가 떠요

Windows 11의 스마트 앱 컨트롤이 켜진 PC에서 생기는 문제예요. 지금은 해결 방법을 준비하고 있으니 Discord에 알려 주세요.

곡 추가가 실패해요

인터넷 연결을 확인한 뒤 다시 시도해 보세요. 그래도 안 되면 오류 창의 자세히 보기 내용을 Discord에 보내 주세요. 오류는 개발자에게도 자동으로 전달돼요.

판정이 늦거나 빠르게 느껴져요

PC와 스피커마다 소리가 늦게 나오는 정도가 달라요. 설정의 싱크 조절 화면에서 한 번 맞추면 판정에 바로 반영돼요. 판정 아래에 FAST가 자주 뜨면 빨리, LATE가 자주 뜨면 늦게 치고 있는 거예요.

곡과 기록은 어디에 저장되나요?

탐색기 주소창에 아래 경로를 붙여넣으면 열려요. 다른 PC로 옮기고 싶을 때 이 폴더를 복사하면 돼요.

%APPDATA%\Godot\app_userdata\TUNEFALL

게임을 지우고 싶어요

Windows 설정 → 앱 → 설치된 앱에서 TUNEFALL을 찾아 제거하세요. 제거할 때 게임만 지울지, 곡 데이터까지 지울지, 설정까지 모두 지울지 고를 수 있어요.
